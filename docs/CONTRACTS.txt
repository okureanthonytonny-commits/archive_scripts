CONTRACTS.txt — who calls who, exact references

RULE OF THUMB FIRST:
- Called "by name" (a bash function, e.g. verify()) only breaks if the
  FUNCTION name changes — renaming the FILE is safe as long as the
  `source` line pointing at it still points at the right path.
- Called "by path" (source "...", python3 "...") breaks the instant the
  filename changes, wherever that exact string appears.
- track.py and summary.py are called BY PATH from the most places —
  renaming either means checking every "Calls" line below.

## multi_month_zipper.sh   (was archive_run_all.sh)
Run by hand: `multi_month_zipper.sh`
Calls:
  - "$SCRIPT_DIR/single_month_zipper.sh" "$month"      [by path]

## single_month_zipper.sh   (was archive_compress.sh)
Run by hand or by multi_month_zipper.sh: `single_month_zipper.sh <YYYY-MM>`
Sources:
  - "$SCRIPT_DIR/lib/common.sh"                          [by path]
  - "$SCRIPT_DIR/lib/single_file_compressor.sh"          [by path]
  - "$SCRIPT_DIR/lib/verify.sh"                           [by path]
  - "$SCRIPT_DIR/lib/delete.sh"                           [by path]
  - "$SCRIPT_DIR/lib/multi_file_pipeline.sh"              [by path]
Calls:
  - process_month "$FILELIST" "$MONTH_STAGE"              [by name]
  - python3 "$SCRIPT_DIR/lib/summary.py" ... > FILE_LOG    [by path]

## build_manifest.sh
Run by hand: `build_manifest.sh [-o OUTPUT] [-a MIN_AGE_DAYS] DIR [DIR2 ...]`
Sources: nothing
Calls: nothing
Writes: archive_manifest.tsv (read by single_month_zipper.sh, by path,
  via $MANIFEST in lib/common.sh)

## lib/common.sh
Exposes (by name — renaming this FILE is safe, function names aren't):
  - log(), set_state(), check_space(), check_space_for_zip(),
    month_to_zipname()
Depends on: nothing

## lib/multi_file_pipeline.sh   (was lib/process_month.sh)
